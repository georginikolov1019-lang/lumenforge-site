# LumenForge Marketing Site

Marketing site for **LumenForge** — AI long-form cinematic video creation.

## Stack
- **Next.js** (App Router)
- **TypeScript**
- **Tailwind CSS**

## Install

```bash
npm install
```

## Develop

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm run start
```

## Scripts

| Command           | Description              |
| ---------------- | ----------------------- |
| npm install     | Install dependencies     |
| npm run dev     | Local development server |
| npm run build   | Production build         |
| npm run start   | Serve production build   |

## Notes

- Waitlist / CTA forms are UI-only (no backend yet).
- Social-proof stats and testimonials use fictional marketing copy.
